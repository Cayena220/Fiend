Safety

What Fiend won't do.

  • Delete a flagged file on its own

    Quarantine moves it into Fiend's vault with its bytes scrambled so it can't run. Restore puts it back exactly where it was.

  • Clear what you're using

    Files newer than a day are kept by default and locked files are skipped. Disk deletions go to the Recycle Bin.

  • Send your files anywhere

    Scanning happens on your PC. The only network request is the optional download of MalwareBazaar's public hash list.

  • Replace your antivirus

    Fiend catches common tricks and asks Defender about anything serious. Keep Windows Security turned on.
